- Automation summaries in Nova use the shared `useModuleStats()` query and invalidate it after automation mutations, so the displayed counts reflect the signed-in user's records rather than examples.- Interval/time automations run on the backend scheduler route (/api/public/hooks/run-automations, called by pg_cron) with atomic claims; the browser runner only handles voice triggers — so automations run without an open tab and never double-execute.
- Chat preflight uses request-local cognitive stages (intent, context, planner, agent selector, tools/skills, verification, memory update, response); keep unimplemented engines explicitly deferred and preserve section tool permissions to avoid implying capabilities that do not exist.
- Cognitive context reads bounded, owner-scoped data through the authenticated request client, treats stored content as untrusted data, and never selects integration tokens; this limits irrelevant context and prevents credential disclosure.
- Persist safe cognitive traces as `data-cognitive-trace` parts on existing assistant messages; this reuses conversation ownership protection without requiring a separate diagnostics table, while failures/cancellations also emit content-free operational traces.
